# AZURE RELIC — 蒼海の翼

公開ゲーム: https://hidecade.github.io/AZURE-RELIC/

`main`へのプッシュ後、GitHub Actionsでテストとビルドを行い、成功するとGitHub Pagesへ自動公開します。

海上遺跡をドラゴンで飛行する、オリジナルの3Dレールシューティング。Panzer Dragoon Episode 1 の海と遺跡、飛翔感、ロックオン攻撃に着想を得ています。原作のアセット・音楽・キャラクターは使用していません。

## 起動

```sh
npm install
npm run dev
```

表示されたローカルURLをデスクトップのブラウザーで開いてください。`npm run build` で配布用ファイルを `dist/` に生成できます。

## 操作

- Enter：飛行開始・一時停止から再開・クリア/失敗後のリトライ
- WASD：現在の視点内で自機を上下左右へ移動
- マウス移動：移動とは独立して照準を操作
- Q / E：左 / 右へ90度ずつ視点を回転
- 左クリック：通常レーザー。長押しで連射
- 右クリック長押し：照準付近の敵を最大6体ロック、離すと追尾レーザーを発射
- Esc：一時停止・再開
- R：前方へ視点を戻す
- M / SOUND：効果音とBGMの切り替え

iPhoneなどのタッチ端末では操作UIを自動表示します（横画面推奨）。左下スティックで移動、右側をドラッグして照準と通常レーザーの自動連射、LOCKボタンを押したままドラッグして照準を動かし、離すと追尾レーザーを発射します。◀ / ▶で90度旋回、「前方」で視点復帰、右上のⅡで一時停止します。画面回転・操作キャンセル・一時停止ではタッチ入力を解除します。PCのキーボード・マウス操作も維持しています。

騎手は青緑の服、革装備、ポニーテールの女性です。横・後方への振り返りと武器の照準追従は共通です。タッチ操作は自動テストで確認していますが、iPhone実機での表示・性能確認は未実施です。

BGMは通常時に `audio/潮の誓い.mp3`、中ボス・最終ボス戦では `audio/星を撃て.mp3` をループ再生します。中ボス撃破後は通常曲に戻ります。一時停止からの再開では続きから、リトライでは通常曲の先頭から再生します。MP3を再生できない環境では、各曲から変換した `audio/tide-oath.ogg` / `audio/shoot-the-stars.ogg` を使用します。

左クリックで長さ4.5・速度70の通常レーザー、右クリックのロックを離すと長さ7・速度62の追尾レーザーを発射します。速度はゲーム内単位/秒です。どちらも敵へ到達したときにダメージが入ります。一時停止、フォーカス喪失、マウスが画面外へ出た場合は攻撃操作をキャンセルします。Spaceと方向キーは使用しません。

Q / Eで前後左右へ振り向けます。自動飛行のコースはそのままで、カメラ・騎手の向き・照準・攻撃が選択した方向へ切り替わります。横・後方を向いたときもドラゴンはコース前方へ飛び続け、騎手が腰・上半身・頭をひねって振り返り、手持ちの武器で攻撃します。切り替え時には照準を中央へ戻し、未発射のロックを解除します。発射済みの追尾レーザーは引き続き標的を追います。

右上のレーダーはコース前方が上の固定方位です。周囲180ゲーム内単位の敵、大型敵、ロックした敵と現在の視野を表示します。後方にいる敵は赤色で示し、後方の敵数と「Q / E で旋回・迎撃」を表示します。通常戦の途中では後方・左右からの増援も登場します。

開始約8秒から、水面に旧時代の小型戦艦が登場します。風化した装甲・艦橋・連装砲塔を持ち、波に揺れながら航跡を残して進みます。砲塔はドラゴンへ向けて射撃します。艦艇はレーダーに四角で表示され、通常レーザーとロックオン攻撃で撃破できます。耐久力は18、基本撃破スコアは600です。

基本コースに沿って自動で前進し、WASDで飛行位置、マウスで照準を独立して調整します。前方視点では照準にドラゴンの首と胴体が追従し、横・後方視点では騎手が照準を追います。移動キーを離しても照準位置は維持します。自機は細い腹部、大きな翼、短い手足を持ち、尾は移動と反対方向になびきます。

移動と照準を同じ方向入力で操作する設計は、[Panzer Dragoon Windows版説明書](https://oldgamesdownload.com/manual/panzer-dragoon-windows-manual-english/)を参考にしています。追従速度や首・胴体のアニメーションは本ゲーム用の調整です。

自機は提供された参考画像に合わせた、青白い装甲状の細身の胴体と濃青の関節、短い手足、上へ反る長い青い尾を持つドラゴンです。青い骨組みと淡い赤茶色の膜を持つ翼を横へ大きく広げ、背中には騎手を乗せています。翼は肩と外翼、尾は11節で動きます。敵には赤褐色と苔色の飛竜が登場し、口から火球を吐きます。

開始約32秒で、中ボス「天翔百足ヴェルミス」が登場します。16体節・32本の脚と小さな翅を持ち、空中をうねって飛びながら弾を放ちます。頭部と各体節を個別にロックオンでき、体節は破壊可能です。中ボスとの戦闘中はステージ進行が止まり、撃破すると編隊戦が再開します。その後約38秒で、最終ボスの古竜アシュガルが登場します。連続撃破でスコア倍率が上昇します。古竜を倒すとクリアです。体力がなくなった場合もリトライできます。

海面は4方向の立体的なうねり、細かい風波、波頭の泡、見る角度によって変化する空と遺跡の反射、太陽光の反射を組み合わせています。近くの波には細かいメッシュを割り当てています。

効果音は `audio/SE` のMP3から変換したPCM WAVをWeb Audioで再生します（元のMP3も保持）。初期状態はSOUND ONです。Enterキーまたは開始ボタンでゲームを始めると音が有効になります。MキーまたはSOUNDボタンで切り替えられます。連射の同時発音数を制限し、ミュート・一時停止・リトライ時には再生中のSEを止めます。短いロック確認音は従来の合成音です。

`audio/SE` をViteの公開フォルダとして読み込み、ビルド時にSEを `dist/` へコピーします。原本の音声ファイルは変更しません。Three.jsによるリアルタイム3DとWebGLが利用可能なデスクトップブラウザー、キーボードが必要です。フォントの取得に失敗してもシステムフォントで動作します。
